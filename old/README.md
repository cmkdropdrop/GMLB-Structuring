# Historical material

This directory is not part of the executable research workflow. It preserves
superseded source layouts, AGILE-specific product material, review artefacts,
papers and historical inputs for traceability.

Nothing under `old/` is imported by the package, used as an operative input or
treated as current methodology. Current code, data and documentation live in
`code/`, `input_data/` and `documents/` respectively.
